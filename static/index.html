启动配置

选择运行后端与固定模型预设，保存后由 Kaggle Worker 加载。

专用 Runtime 固定挂载 Qwen 与 Ornith 两套私有 Dataset；未选择的模型不会进入内存或显存。模型、视觉投影与运行时路径通常留空即可。
